# Supplementary repository release scope

This release updates the existing private `lucaswhd/dissertation` repository without changing its name, owner, or visibility. The dissertation author authorised use of original research code and selected numerical evidence for the thesis and this repository. Existing source notices and upstream software licences remain in force; no blanket relicensing is asserted.

The current release adds documentation, sanitised provenance and checkpoint summaries, a prediction identity/schema manifest, and copies of the executed verification scripts. It does not add raw BEHAVIOR HDF5, restricted OmniGibson scene/human assets, recorded camera frames, simulator videos, model checkpoints, saved prediction arrays, training caches, or a complete simulator installation. The final manuscript PDF and LaTeX source remain in controlled delivery pending a separate third-party rendered-asset rights review.

Superseded no-push instructions, old Word-layout checks and development-version delivery reports were removed from the current tree. Git history and the earlier submission tag preserve the prior materials. This document describes the curated supplementary repository release.
