# Dataset schema and source units

The unit of splitting is a **complete retained HRC source**, not an individual frame or action chunk. Quality control retained 45 of 65 collected sources and froze 37 train, four validation and four test sources. The recorded total is 409,670 frames at 30 Hz. Each retained source has two ordered rounds: cleanup and radio interaction. Human-facing transition and navigation phases are scripted; task-execution manipulation in the dataset replays an upstream demonstration.

The continuous LeRobot export provides head RGB observations at 352×256 before model preprocessing, 23 physical state coordinates, task/phase text, and 23 physical action coordinates. Wrist image slots are masked placeholders. The policy interface pads actions to 32 dimensions. For a source frame `t`, the next-action target begins at raw action `t+1`; a 32-step chunk must stay within the same source and coarse context. The terminal repeated-action sentinel is not an eligible training target.

Decision frames are sparse relative to all valid B/C anchors. The configured 20% sampling target is not the observed fraction of recorded decision rows or proof of the realised sampling frequency. Use actual validity masks and exported rows when checking counts; the inherited B manifest contains some A-era count fields. See `docs/DATASET_MANIFEST.md` and `reports/DATASET_AUDIT.md` for historical export details.

`evidence/provenance/source_mapping_sanitized.csv` has one row per retained HRC source. It includes the frozen split, hash of the final HRC HDF5, each upstream raw demonstration identifier and full-file SHA-256, canonical action/state hashes, and a Boolean for exact task-execution action replay. It omits private absolute paths and raw content. The 90 upstream raw file hashes are unique across both rounds, and all 90 replay checks are true. This supports the absence of exact complete-demonstration reuse within the audited population; it does not establish broader scene, object, task or behavioural independence.

The source and frame counts can be checked without the restricted dataset using `python3 tools/verify_released_evidence.py`. Re-running the original raw-file audit requires authorised access to the upstream HDF5 files, final HRC batch, LeRobot export, and the original research environment. The full executed audit remains in the controlled server evidence directory.
